# Aplikasi Kasir (Point of Sale)
## 📖 Latar Belakang
Di era digital saat ini, banyak usaha kecil seperti warung, toko kelontong, dan UMKM
masih melakukan pencatatan transaksi secara manual.
Hal ini sering menimbulkan masalah seperti kesalahan perhitungan,
kehilangan data penjualan, dan kesulitan dalam membuat laporan.

Berdasarkan permasalahan tersebut, penulis mengembangkan sebuah
**Aplikasi Kasir (Point of Sale)** yang dapat membantu proses transaksi
menjadi lebih cepat, rapi, dan terstruktur.

## 💡 Ide Proyek
Aplikasi Kasir ini dirancang sebagai sistem sederhana namun profesional
yang dapat digunakan oleh kasir untuk mencatat transaksi penjualan,
mengelola data produk, serta melihat laporan penjualan.

Aplikasi ini dibuat dengan tampilan modern agar mudah digunakan
dan memberikan pengalaman seperti aplikasi kasir sungguhan
yang biasa digunakan di dunia usaha.

## 🎯 Tujuan
Tujuan dari pembuatan aplikasi ini adalah:
- Mempermudah proses transaksi penjualan
- Mengurangi kesalahan perhitungan total belanja
- Membantu pemilik usaha dalam melihat laporan penjualan
- Menjadi solusi digital sederhana untuk usaha kecil dan menengah

## 👥 Target Pengguna
- Kasir toko
- Pemilik UMKM
- Pengusaha kecil
- Pengguna yang membutuhkan sistem kasir sederhana

## 🧩 Fitur Utama
- Login & autentikasi pengguna
- Manajemen data produk (tambah, edit, hapus)
- Transaksi penjualan dengan perhitungan otomatis
- Pengelolaan jumlah barang (quantity)
- Riwayat transaksi
- Laporan penjualan
- Tampilan dashboard informatif

## 🏁 Penutup
Dengan adanya aplikasi kasir ini, diharapkan proses transaksi
dan pencatatan penjualan dapat berjalan lebih efektif dan efisien.
Aplikasi ini juga menjadi salah satu implementasi nyata dari
penerapan pemrograman mobile dalam menyelesaikan permasalahan sehari-hari.
